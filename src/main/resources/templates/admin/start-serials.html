Стартовые номера серий

Серийные номера в прежней базе уже выданы, и новая база не вправе их задваивать. Здесь задают номер, с которого начинается выдача по каждому классификатору. Пустое поле — ряд начинается с единицы.

Стартовый номер — нижняя граница выдачи, а не положение счётчика: занятые номера реестра остаются занятыми. Значение ниже пройденного максимума не ошибка, а избыточность — система выдаст следующий за максимумом номер.
