Внесение данных входного контроля

Перенос журнала входного контроля комплектующих из файла Microsoft Excel в журнал бюро входного контроля. Строки листа попадают в тот же журнал, который ведут контролёры БВК руками, и проходят те же проверки: поставщик, количество проверенного и брака.

Файл сначала разбирается и показывается в предпросмотре — в базу он не записан. Внесение подтверждают отдельной кнопкой; до подтверждения лист можно отменить и загрузить другой.

Файл журнала

Лист журнала: дата контроля, наименование, поставщик, количество, реквизиты документа и акта. Колонки находим по заголовкам в файле — порядок вкладок значения не имеет, система сама выбирает самый свежий лист.

Microsoft Excel: .xlsx или старый .xls. Если в книге несколько листов, берутся строки самого свежего по дате контроля.
Сотрудники БВК и БТК. Имя контролёра становится подписью каждой внесённой строки, поэтому его выбирают до внесения, а не после.
