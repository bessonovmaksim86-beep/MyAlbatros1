# Агент печати этикеток

Агент печати запускается на компьютере кладовщика и передаёт номера
партии в локальный BarTender, который стоит на том же компьютере.

Сервер приложения (Spring Boot) работает на удалённой машине, и
запустить BarTender на компьютере пользователя напрямую не может —
браузер не даёт веб-странице запускать программы, а сервер не видит
установленный у кладовщика BarTender и его принтер.

Поэтому на машине кладовщика ставят этот агент: страница обращается
к нему по адресу 127.0.0.1:7788, а агент запускает локальный
bartend.exe с нужными параметрами.

## Требования

- Java 17 или новее (JRE достаточно). Проверка: `java -version`
- BarTender Suite 2022 (или совместимая версия)
- Шаблон этикетки `.btw` с полями:
  `NUMBER, INDEX, CLASSIFIER, NAME, ORDER, SHOWTEXT`
- Принтер этикеток, подключённый к компьютеру (или сетевой принтер)

## Схема работы

```
Компьютер кладовщика                     Сервер приложения
┌──────────────────────────┐            ┌────────────────────┐
│ Браузер                  │            │ Spring Boot        │
│  http://10.0.0.127:8080  │──HTTP─────▶│ 10.0.0.127:8080    │
│                          │            └────────────────────┘
│  fetch → 127.0.0.1:7788  │
│         │                │
│         ▼                │
│  Агент печати            │
│         │                │
│         ▼                │
│  BarTender → принтер     │
└──────────────────────────┘
```

Кладовщик открывает приложение по адресу сервера
(`http://10.0.0.127:8080`), а печать вызывает на **своём** компьютере
через `127.0.0.1:7788`. Поэтому в настройках сервера указывается
именно `http://127.0.0.1:7788` — этот адрес браузер кладовщика
понимает как его собственный компьютер, а не как сервер.

Адрес `http://10.0.0.127:7788` указывать **нельзя**: на сервере
агента нет, и порт 7788 там закрыт.

## Установка

1. Скопируйте папку `print-agent/` на компьютер кладовщика
   (например, `C:\print-agent\`).

2. Откройте `agent.properties` в блокноте и укажите пути:

   ```properties
   bartender.path=C:\Program Files\Seagull\BarTender 2022\BarTend.exe
   template.path=C:\BarTender\yacheika.btw
   ```

   Остальные параметры обычно не меняются. Если принтер не указан
   — BarTender использует принтер, записанный в шаблоне.

3. Сохраните файл и запустите `run-agent.bat`.

4. Проверьте: откройте в браузере
   `http://127.0.0.1:7788/health` — должен вернуться JSON с
   `"ready":true`.

## Автозапуск при входе в систему

Чтобы агент запускался автоматически при входе кладовщика:

1. Создайте ярлык `run-agent.bat`
2. Поместите его в папку автозагрузки:
   `C:\Users\ИмяПользователя\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\`

Агент можно настроить на тихий запуск (без окна консоли) через
`RunAgent.vbs` — см. ниже.

## Диагностика

- Логи агента: `print-agent.log` рядом с `agent.properties`
- Проверка готовности: `http://127.0.0.1:7788/health`
- Если агент не отвечает — проверьте, запущен ли процесс `PrintAgent`
  в Диспетчере задач, и есть ли Java в PATH.

## Тихий запуск (без окна консоли)

Если не хотите видеть окно консоли, создайте файл `RunAgent.vbs`
рядом с `run-agent.bat`:

```vbs
Set WshShell = CreateObject("WScript.Shell")
WshShell.Run "run-agent.bat", 0, False
```

Двойной клик по `RunAgent.vbs` запустит агент в фоне.

## Структура файлов

```
print-agent/
├── PrintAgent.java          ← исходный код (собирается javac)
├── PrintAgent.class         ← скомпилированный класс
├── PrintAgent$Config.class  ← вложенный класс (конфигурация)
├── agent.properties         ← настройки (пути, порт, токен)
├── run-agent.bat            ← запуск
├── RunAgent.vbs             ← тихий запуск (опционально)
└── print-agent.log          ← журнал (создаётся автоматически)
```

## Формат файла данных

Агент записывает файл данных в том же формате, что и серверная
печать. Строка заголовка и по строке на номер:

```
NUMBER	INDEX	CLASSIFIER	NAME	ORDER	SHOWTEXT
500100001	1	5001	Подсборка ЯПР56	2026-0101	1
500100002	2	5001	Подсборка ЯПР56	2026-0101	1
```

Разделитель — табуляция (настраивается в `agent.properties`).

Шаблон `.btw` должен импортировать этот файл как источник данных.
Поле `SHOWTEXT` управляет выводом числового номера текстом над QR.

## Настройка сервера

На сервере приложения укажите адрес агента:

```yaml
application:
  label-printing:
    agent-url: http://127.0.0.1:7788
    agent-token: ваш-секретный-токен
```

Агент должен получить тот же токен:

```properties
token=ваш-секретный-токен
```

Если токен задан, агент принимает печать только с заголовком
`X-Print-Token` с этим значением.

## Безопасность

Агент слушает только 127.0.0.1 (петлевой интерфейс). Из локальной
сети к нему невозможно подключиться. Однако любой сайт в браузере
на этом компьютере может обратиться к агенту — токен предотвращает
случайные запросы от других расширений или страниц.

Отдельно учтена защита Chrome Private Network Access: страница
открыта по адресу сервера в локальной сети, а печать вызывает
агента на 127.0.0.1 — для браузера это переход в локальную сеть.
Агент отвечает заголовком `Access-Control-Allow-Private-Network: true`,
без которого Chrome блокирует такие запросы.

Если браузер всё же блокирует печать, проверьте консоль разработчика
(F12): сообщения вида `blocked by CORS policy` или
`Private Network Access` означают, что запрос не дошёл до агента.
